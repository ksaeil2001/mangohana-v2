# S16-05 작품별 짝비교와 비용 보정 검증

2026-11-19 KST. 모델 A와 B 각각에서 같은 페이지의 기존 처리와 개선 처리를 비교하는 오프라인 보고서를 구현했다. 합성 3작품·5페이지에서 요청된 오류 3건과 분수 반올림 오류 1건을 재현했다. 최종 집중 **25/25**, 관련 회귀 **24/24**가 통과했다. [합성 보고서 원본](stage16-05-20261119/synthetic-report.json) · [실행·지문 기록](stage16-05-20261119/test-runs.json) · [종료 Handoff](../superpowers/handoffs/2026-11-19-stage16-s05-handoff.md)

## 입력과 계산 기준

S16-02에 동결한 작품·페이지 목록에서 시작한다. S16-03의 실행 관측과 S16-04의 블라인드 반환 원장, 사전등록한 자동 평가기의 저장 점수를 모델·처리·최종 결과 지문에 맞춰 연결한다. 이전 Handoff의 합성 봉인표와 반환 묶음도 그대로 회수해 연결했다. 누락된 영수증, 평가 미발급, 열린 불일치, 판단 불가, 미응답은 예정된 쌍에 남는다. 원장 자체가 잘리거나 다른 실험의 행이 들어오면 입력 오류를 반환한다. [공개 함수](../../packages/evaluation/stage16-paired-report.mjs) · [집중 검사](../../tests/v2/stage16-paired-report.test.mjs)

- 사전등록 지표 `work_paired_score`의 주축을 의미 충실도로 해석했다. 개선 선호는 +1, 기존 선호는 −1, 동점은 0이다. 중복 평가에서는 배정된 두 응답이 해당 축에 일치해야 점수를 준다. 자연스러움에도 같은 집계를 적용하고 사전등록한 비열등성 허용치와 비교한다.
- 한 작품 안에서는 예정된 각 페이지, 모델 안에서는 각 작품에 같은 가중치를 준다. 확인된 승리 비율의 분모는 예정된 모든 페이지다. 결측이 있는 전체 평균은 `null`이며, 각 결측이 −1부터 +1일 때 가능한 범위를 함께 낸다. 작품별 정수 투표 차이를 분수로 더한 뒤 소수로 변환한다.
- 자동 평가 점수는 동일한 사전등록 평가기에서 나온 0~1 값이며 큰 값이 좋다. 같은 축의 개선 점수에서 기존 점수를 빼 방향을 구한다. 불일치율은 사람 쪽 선호와 자동 쪽 방향이 모두 있는 쌍을 분모로 삼고, 예정 수와 비교할 수 없는 수도 함께 기록한다. 동점과 방향성 선호가 만나면 불일치 1건이다. 각 축에는 원래 두 자동 점수, 평가자별 선택 방향과 결측 사유가 남는다.

## 다섯 페이지 손계산

X는 1~3쪽, Y는 4쪽, Z는 5쪽이다. `+`는 개선 선호, `−`는 기존 선호, `0`은 동점이다. 아래 사람·자동 열은 모두 합성 입력이다. 자동 열에는 점수 차이의 방향을 표시했다. [재현용 입력](../../tests/v2/fixtures/stage16-paired.mjs)

| 모델·축 | 블라인드 선호 1~5쪽 | 자동 방향 1~5쪽 | 작품 동일 가중 선호 평균 | 자동·사람 불일치 / 비교 가능 | 비교 불가 / 예정 |
|---|---|---|---|---|---|
| A 의미 | +, +, 0, −, 결측 | +, 0, 0, −, 결측 | 미확정. 가능한 범위 [−4/9, +2/9] | 1/4 | 1/5 |
| A 자연스러움 | 0, +, 의견 갈림, 0, 결측 | 0, +, −, 결측, 결측 | 미확정. 가능한 범위 [−1/3, +5/9] | 0/2 | 3/5 |
| B 의미 | 0, −, −, +, 0 | 0, −, 0, −, 0 | +1/9 | 2/5 | 0/5 |
| B 자연스러움 | +, 0, −, 0, 0 | +, 0, −, 0, 0 | 0 | 0/5 | 0/5 |

A 의미는 개선 2·기존 1·동점 1·결측 1이다. 확인된 개선 비율은 **2/5 = 40%**다. X 평균은 +2/3, Y는 −1, Z는 결측이다. 따라서 하한은 (2/3 − 1 − 1)/3 = −4/9, 상한은 (2/3 − 1 + 1)/3 = +2/9다. A 자연스러움에서 3쪽은 두 평가자가 갈렸고 4쪽은 자동 점수가 비어 있다. 양쪽을 비교할 수 있는 쪽은 1·2쪽뿐이다.

B 의미는 페이지를 합치면 (0 − 1 − 1 + 1 + 0)/5 = −1/5다. 작품별로 계산하면 X가 −2/3, Y가 +1, Z가 0이므로 **(−2/3 + 1 + 0)/3 = +1/9**다. 합성 실험에 미리 등록한 최소 차이 +0.20에 못 미친다. B 자연스러움의 관측 차이는 0이다. 허용치 0.02 안에 있는 관측값과 비열등성을 뒷받침할 표본 근거는 별도로 기록했다.

## 표본 불확실성

독립이고 오류 확률이 같은 표본에서 오류 0건이 나올 확률은 (1 − p)ⁿ이다. 이를 0.05로 두면 단측 95% 오류율 상한은 **1 − 0.05^(1/n)**이다.

| 독립 표본 수 | 오류 0건에서의 상한 |
|---|---|
| 100 | 2.95130% |
| 298 | 1.00024% |
| 299 | 0.99691% |

작품 간 평균 차이에는 별도 계산을 쓴다. 독립적으로 표집한 작품과 [−1, +1]의 작품 평균을 가정한 양측 95% Hoeffding 구간이다. 결측을 채웠을 때의 하한·상한에서 각각 √(2 ln(40)/작품 수)만큼 넓힌 뒤 [−1, +1]로 제한한다. 세 작품에서 반폭은 약 1.5682이고 B 의미의 구간은 **[−1, +1]**이다. 한 작품뿐이거나 서로 다른 작품에 같은 누출 그룹·문맥 지문이 있으면 작품 간 구간을 보류한다. 독립성은 표집 가정이다.

B 자연스러움에서 자동·사람 불일치를 한 건이라도 포함한 작품은 0/3편이다. 그 사건에 대한 조건부 단측 상한은 **63.16%**다. 독립 표본 100·299건 예시는 번역 결함을 실제로 측정한 결과와 구별해 보고서에 담았다. [실제 출력](stage16-05-20261119/synthetic-report.json)

## 비용 보정 성공

이 보고서의 성공 1건은 두 결과가 완주했고 의미 충실도에서 해당 처리가 이긴 페이지다. 각 처리에 배정한 모든 작업의 USD를 합산한다. 반복 작업과 실패한 작업의 확인 비용도 포함한다. 두 처리를 합친 비교 비용에는 개선 승리 수를 대응시킨다. 성공 수/비용과 비용/성공 수를 함께 제공한다. [계산 코드](../../packages/evaluation/stage16-paired-report.mjs)

| 모델·비용 범위 | 확인된 의미 승리 | 확인 부분합 USD | 총액 USD | 성공/USD | USD/성공 |
|---|---|---|---|---|---|
| A 기존 | 1, 미판정 1 | 0.50 | 0.50 | 미확정 | 미확정 |
| A 개선 | 2, 미판정 1 | 1.00 | 미확정 | 미확정 | 미확정 |
| A 두 처리 합계 | 개선 2, 미판정 1 | 1.50 | 미확정 | 미확정 | 미확정 |

별도 합성 사례에서는 승리한 페이지의 비용 하나가 미정이면 승리 수를 보존하면서 총액과 효율을 `null`로 남겼다. 확인된 0 USD, 승리 0건, 다른 결과를 낸 반복 작업의 0.000000000001 USD도 각각 검사했다.
