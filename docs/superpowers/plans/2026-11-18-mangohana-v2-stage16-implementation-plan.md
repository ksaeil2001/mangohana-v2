## S16-01 입력과 출력

표준입력 JSON 하나가 작품·페이지 ID와 동일 원본, 폰트 묶음, 공통 설정, 문맥 스냅샷의 SHA-256을 제공한다. `intermediateSha256`은 고정 중간 입력 묶음의 SHA, 전체 경로를 지정할 때는 명시적 `null`이다. `models.A/B`는 각 모델 버전 명세의 지문, `processing.baseline/improved`는 각각의 처리 버전 명세 지문이다. 출력은 공통 입력, 네 조건과 전체 조건표 SHA다. 실제 파일 내용·사람 권리·결과·실험 잠금은 후속 단계의 증거가 필요하다. 이 입력의 네 조건 표기 순서는 내부 식별용이며 사람에게 보일 제시 순서는 S16-04에서 배정한다.

검사는 실제 Stage15 실행 파일과 같은 Node에서 수행한다. 허용 변경은 위 세 파일, 이 계획, 검증 근거, 기존 V2 진행 계획의 끝 기록과 Handoff다. Stage14/15의 기존 산출물·원장·검증 원본은 읽기 전용으로 대조한다. 현재 개발 판정과 다음 재개 지점은 [검증 보고서](../../validation/2026-11-18-v2-stage16-kickoff.md)에 기록한다.

## S16-04 종료 기록

동결된 합성 페이지에 대해 모델별 기존·개선 쌍을 만들었다. 사전등록한 비밀로 중복 페이지와 평가자별 A/B 순서를 재현하고, 평가지에는 익명 참조와 두 질문을 담았다. 중복 평가의 의미 불일치와 자연스러움 일치를 각각 보존했다. 합성 배정 6건의 결과는 두 축 응답 2건, 한 축 응답 1건, 발급 후 무응답 2건, 결과 누락 미발급 1건이다. [회수 예시](../../validation/stage16-04-20261119/synthetic-recovery.json)

첫 검사부터 허용 목록과 이미지 차단기를 적용했다. 최초 RED 7건과 보강 RED 3건을 재현했고 최종 집중 21/21, 관련 회귀 23/23을 확인했다. 실제 자료·모델·Permit·사람 평가·이미지 처리 없이 S16-04에서 종료했다. [검증 보고서](../../validation/2026-11-19-v2-stage16-blind-review.md) · [현재 Handoff](../handoffs/2026-11-19-stage16-s04-handoff.md)

## S16-05 종료 기록

모델별로 기존·개선 처리의 의미와 자연스러움을 짝지어 작품 안에서 페이지를 평균하고 작품마다 같은 가중치를 줬다. 합성 3작품·5페이지에서 A 의미의 확인된 개선은 2/5, B 의미의 작품 평균은 +1/9이었다. 독립 무결함 100·299건의 오류 상한, 작품 간 구간, 자동·사람 불일치 분모, 미확정 비용의 부분합을 손계산과 대조했다. [합성 보고서](../../validation/stage16-05-20261119/synthetic-report.json)

최초 RED 3건과 분수 반올림 RED 1건, 최종 집중 25/25·관련 회귀 24/24를 확인했다. 첫 검사부터 이름 허용 목록과 이미지 차단기를 적용했다. 실제 자료·모델·Permit·사람 평가·이미지 처리 없이 S16-05에서 종료했다. [검증 보고서](../../validation/2026-11-19-v2-stage16-paired-report.md) · [현재 Handoff](../handoffs/2026-11-19-stage16-s05-handoff.md)
