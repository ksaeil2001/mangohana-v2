## 최종 회귀 반영

TRIO에서 가져온 페이지 이름에 장 경로가 있으면 결과 ZIP 안에 폴더가 생기는 경우를 재현해 수정했다. 원래 이름은 프로젝트와 페이지 목록에 보존한다. 최종 후보에서 Studio 239/239, 관련 표적 111/111, 원본 v29 CSS 대조 1/1, 두 타입 검사가 통과했다. 오프라인 Chrome 1/1은 파일 선택부터 수정·새로고침·재가져오기까지 확인했다. [최종 Chrome](../../validation/stage17-18-20261119/browser-checkpoint.log) · [Studio](../../validation/stage17-18-20261119/web-current.json)

V2 회귀는 1,330/1,340 통과, 7개 실패, 3개 시간 초과였다. 영향이 관측된 기존 5개 파일을 기존 한도 그대로 분리해 실행한 결과는 34/40이었다. 세 번 시간 초과한 Electron 누락 plan은 전용 폴더의 단일 실행에서 2.58초 만에 예상 오류·커널 정리까지 확인했다. 식자 controller 영수증 6개에서 정리는 확인됐고, 네이티브 종료 오류의 최초 원인은 미확정이다. 체크리스트의 전체 회귀는 `FAIL`, 실제 출하는 `BLOCKED`다. [전체 회귀](../../validation/stage17-18-20261119/v2-current.json) · [단독 5파일](../../validation/stage17-18-20261119/native-current.json) · [단일 사례](../../validation/stage17-18-20261119/entry-witness.log) · [최종 체크리스트](../../validation/stage17-18-20261119/release-final-check.log)

Stage18의 운영 판정기는 이 실제 회귀 결과를 받아 합성 검토에서 `ROLLBACK`을 반환했다. 파일은 미커밋 상태로 보존했고 실제 배포·복원은 실행하지 않았다. [Stage18 최종 인계](2026-11-19-stage18-handoff.md)
