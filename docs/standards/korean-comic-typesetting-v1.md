PDF 규칙과 이번 사용자 요청을 함께 적용하며, 실행·승인 권한은 현재 사용자 요청만 따른다.

## 적용 범위와 판정

일반 한국어 가로쓰기 speech/thought, 회전 0도, rectangle/ellipse/rounded_rectangle에 공통 정책을 적용한다. 세로쓰기·효과음·손글씨·특수 모양·회전 대사는 기존 경로를 유지하고 `NOT_APPLICABLE / SPECIAL_PROFILE_REQUIRED`로 구분한다. 이를 일반 한국어 합격으로 표시하지 않는다. 호출자가 사후 보고서의 모양만 바꾸어 일반 프로필 검사를 피할 수 없다.

`BLOCKED`는 HARD 위반, `WARN`은 HARD 위반 없이 SOFT 검토가 필요함, `PASS`는 해당 증거 단계의 HARD/SOFT 검사 통과다. 이 값은 작업 실행 상태나 사용자 승인 상태가 아니다. `SOURCE_METRICS`의 PASS/WARN에는 실제 cleaned 배경·최종 래스터·겹침·글리프 확인이 남는다. `FINAL_RASTER`는 실제 픽셀 증거까지 필요하다. 공통 정책은 스스로 사용자 승인을 발급하지 않는다.

## 권장 규칙과 후보 탐색

| ID | 권장 내용 | 구현 및 한계 |
|---|---|---|
| S-01 | 의미·호흡 단위 우선 | 공백/부호/수식어 말미의 결정적 휴리스틱. 의미를 새로 추론하거나 사람 검수를 대신하지 않음 |
| S-02 | 일반 대사 약 5~10자/행 초기 목표 | 공백 제외 grapheme 수 경고. 합격 제한이나 강제 축소 기준 아님 |
| S-03 | 짧은 감탄사 한 행, 일반 대사 2~3행 우선 | 한 어절 한 행은 H-02로 보호. 4행 이상은 WARN 비교 대상으로 유지 |
| S-04 | 마지막 1~2글자 고립 방지 | 다른 행이 충분히 긴 경우 고립 경고. 강제 삭제/병합 금지 |
| S-05 | 모양에 맞는 글자 덩어리 | 타원/직사각형 행 길이 균형의 실험적 점수 |
| S-06 | 장면의 상대적 크기·행간·정렬 일관성 | 유사 폭의 같은 논리적 말풍선 비교와 스타일 경고. 장면/화자 판독이 아니라 공간 휴리스틱임 |

권장 행간 1.2~1.4는 SOFT다. 기존 수동 경로 최소 행간 1.25 등 안전 조건이 우선한다. 승인된 한 행 C안의 1.5를 변경하거나 경고를 만들기 위해 적용하지 않는다.

공통 줄바꿈은 어절 경계에서 bounded DP를 수행한다. 실제 폰트 폭 콜백을 사용하고, 불가능한 어절은 분절·누락하지 않고 넘침으로 검출한다. 자동 fit은 기존 크기 탐색 범위 안에서 가독성 점수를 비교한다. 수동 후보 비교는 허용 ROI 안의 위치/박스·크기·행간 조합을 실제 폰트로 측정한 뒤 HARD·원본 보호를 통과한 후보만 순위에 올린다. SOFT 점수와 가능한 최대 크기를 함께 고려하고, 거의 같은 점수에서는 경고가 적은 후보를 우선한다. 점수 가중치는 실험적이며 사람의 가독성 합격률을 의미하지 않는다.

`비교 기준 · 미승인 후보`는 이전 추천안의 정확한 좌표·크기·명시적 줄바꿈을 재측정한다. `크기 우선 비교안`은 현재 알고리즘의 크기 우선안이며 과거 추천안과 구분한다. 비교 기준 URL은 영역 ID·수치·공백 줄 경계만 전달한다. 승인 번역은 서버 세션 자료에서 가져오고 서버가 현재 owner/revision/ROI와 다시 대조한다.

독립된 영역의 후보 순위에는 현재 원본 자동안의 상대 크기가 들어간다. 함께 선택할 다른 후보가 아직 정해지지 않은 상태이므로 이를 조합 전체의 최적성으로 확대하지 않는다. 실제 측정한 공유 말풍선 후보를 함께 비교할 때는 그 크기로 S-06을 다시 평가한다. 이번 5번 30px 기준에서 6번의 3행 20px에는 상대 크기 WARN이 추가되고, 4행 25px가 더 균형 잡힌 비교 후보로 남는다. 이 조합 평가도 미저장·미승인이며 사람의 가독성 합격을 대신하지 않는다.

공유 말풍선 미리보기는 같은 비교안이 있으면 그것을, 없으면 측정된 추천안을 표시하고 영역·이름·실제 크기를 적는다. 이는 출처가 같은 논리적 흰 성분의 원본 상한에 기반한 보조 표시이며, 의미상 말풍선을 합치거나 OCR ID를 바꾸지 않는다.

## 승인 및 최종 경계

미저장 후보를 표시·비교하는 행위는 저장이나 승인이 아니다. 새 WARN 수동 승인은 버전·경고 코드·현재 측정/코드의 `standardReviewSha256`와 계획 해시에 결합한다. 과거 C 승인 영수증은 변경하지 않는다. 실제 최종 WARN도 승인된 해당 계획과 검토된 경고 코드가 있어야 한다. 새 경고나 HARD 위반을 자동 승인으로 바꾸지 않는다.

Stage12는 cleaned 배경과 실제 투명 잉크를 검증하고 imported contract에서 다시 검사한다. Desktop/vendor의 일반 가로쓰기 Blob 내보내기는 `validateFinalKorean` 증거를 요구한다. 기존 UI에 최종 안전 영역 검증기를 연결하지 않은 내보내기는 `TYPESETTING_FINAL_VALIDATION_REQUIRED`로 차단한다. source-only 플래그를 대신 넘겨 내보내는 우회는 허용하지 않는다. 특수 프로필의 기존 동작은 유지한다.
