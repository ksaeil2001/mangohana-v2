# Triage labels — 비활성 참고 어휘

triage 스킬은 플러그인에 포함되어 있지만 MangoHana의 기본 개발 흐름에는 연결하지 않는다. 아래는 공식 기본 역할의 참고 매핑이며 현재 GitHub 레이블의 존재·정책을 확인했다는 뜻이 아니다. 이번 설정은 레이블을 생성하거나 적용하지 않는다.

| 역할 | 참고 레이블 | 의미 |
|---|---|---|
| needs-triage | needs-triage | 검토 필요 |
| needs-info | needs-info | 정보 필요 |
| ready-for-agent | ready-for-agent | 에이전트 작업 준비 |
| ready-for-human | ready-for-human | 사람 작업 필요 |
| wontfix | wontfix | 수행하지 않음 |

실제 triage 요청 시 기존 원장과 레이블을 확인하고 이 파일을 맞춘다. 설치만으로 원격 쓰기 권한이나 자동 triage를 부여하지 않는다.
