# 엔진 설정의 오른쪽 패널 이동

기준 소스 `bb10676` (Sites v16). 사용자가 지정한 톱니바퀴의 연결 설정창을 기존 오른쪽 패널 안으로 옮긴다.

- 오른쪽 패널은 텍스트 도구/엔진 설정 두 보기로 전환한다. 상단 로컬·온라인 선택과 처리·다운로드는 유지한다.
- 엔진 설정은 별도 컴포넌트로 분리하고 패널 내부에서만 스크롤한다. 닫기·저장 후 텍스트 보기로 돌아온다.
- 엔진 모드 버튼은 기존 상단의 한 쌍을 공유한다. 언어·주소·연결 검사·저장 동작을 유지한다.
- 설정 안에 포커스가 있으면 Ctrl+S와 단일키 캔버스 명령을 가로채지 않는다. Esc는 설정을 먼저 닫고 다음 Esc가 모바일 drawer를 닫는다.
- 패널이 숨겨지거나 모달·프로젝트·처리 모드가 바뀌면 진행 중 연결 검사를 무효화한다. 설정창을 다시 열 때 주소 초안은 저장값에서 시작한다.
- 기존 프로젝트·파일 형식·접근 범위를 보존한다. OCR JSON/이름 변경 항목의 제거 상태를 유지한다.

검증은 기존 검사와 새 키보드 소유권 검사, TypeScript, 데스크톱/좁은 화면의 설정·닫기·저장·캔버스 편집, 배포 빌드로 한다.
